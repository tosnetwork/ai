# Token buyer adapter verification

This is local implementation evidence, not a public-network acceptance run.
The base is the token protocol work at `db64ef393d4376a17b25d2b1834fe387ee7a03ab`,
with main through `2addb7742b9ad4cf6e548812a94ba50812df7516` merged.
The existing native encodings and native confirmation domain are retained;
token call records, confirmations, receipts and exports select explicit versions.

## Commands and results

Run with `GOWORK=off`, under the thermal guard. Supply the existing pinned custody
helper, its SHA-256, and the fixture checkout through `TOS_SERVICE_TOSCTL`,
`TOS_SERVICE_TOSCTL_SHA256` and `TOS_SERVICE_TOKEN_CLI_REPO`; no helper build is
part of this change.

```
go test -json -p 4 ./protocol/pkg/buyersdk ./protocol/pkg/buyeragent \
  ./protocol/pkg/buyerconfirm ./protocol/pkg/mcpbuyer ./protocol/pkg/quoteprovider \
  ./protocol/pkg/railwork ./protocol/pkg/serviceactorindex \
  ./protocol/cmd/tos-service-buyer ./gateway/internal/nativegateway \
  ./gateway/internal/quotesource
go vet -p 4 <the same ten packages>
make spec-check schema-check boundary-lint
```

All ten packages passed: 390 top-level test passes (510 including subtests).
The only reported skip is the existing `TestTerminalChild` helper, which is
invoked separately by its parent terminal test. Vet, spec reproduction, schema
comparison and all platform/source import-boundary checks passed. Changed Go
files are gofmt-clean; whitespace checks passed. No Rust build ran.

Sixteen temporary overlay controls each failed the intended test, followed by
a green unmodified run: five SDK controls (durable custody gate, principal cap,
lifecycle funding cap, bounce flag, exact funding), four adapter controls
(confirmation, preview, asset pin, receipt price), three discovery/quote controls
(two acceptance guards and atomic price), two receipt controls (asset and schema),
one gateway dispatch control and one evidence message-hash control. Overlays do
not mutate production files.

## Scope and review

The token wallet's pinned code transfers its principal without a transfer fee;
this does not claim support for arbitrary fee-charging wallet code. A real
independent-provider purchase and independent evidence verification remain the
network acceptance gate. Provider execution/delivery changes belong to their
own work item.

Upstream comparison: these buyer, gateway and token protocol paths are specific
to this repository and absent from the inherited core upstream tree at
`99143587e6babb2e577eadea0fc741cb1b413fab`; there is no upstream fix to port.

Author self-check covers callers, persistence/custody order, sibling native/token
paths, configuration and versions, rejection controls, documentation and current
base. Applicable review areas: resource bounds, concurrency, persistence, custody,
serialization, configuration, compatibility, API errors, value-moving tooling
(VM-1 through VM-9), observability, tests, build boundaries and hygiene.
A non-author review is still required before merge.
